# ORE Reference Engine

TypeScript reference implementation of the ORE calculation methodology: monthly and
annual cash flows, NOI bridge, unlevered/levered IRR, NPV, direct cap value, per-SF
metrics, sensitivity tables. Pure functions, zero UI dependency; runs in browser and
Node. Planned package name: `@ore-format/engine`.

Not started — lands after the v0.1 schema modules are complete. Conformance for any
implementation (including this one) is defined by the golden-file test suite:
reproducing locked expected outputs for every example deal, exactly.
