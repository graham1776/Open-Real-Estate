ORE (Open Real Estate) is an open, JSON-based file format for commercial real estate underwriting data, and an open-source engine that computes it. One file carries the rent roll, expenses, assumptions, and valuation. Anyone can read it, write it, and check the math.

Plain JSON with a published schema. Field names carry their units, conventions are stated in the file, and the underwriting assumptions travel with the data.

The same deal in the viewer

Drop a .ore file and the reference engine computes NOI, cash flows, DCF and direct cap values, levered and unlevered returns, and a sensitivity grid. Anything it estimated is listed in a Warnings tab.

Why

Rent rolls, lease abstracts, operating histories, and underwriting assumptions move between brokers, buyers, and appraisers in formats that force re-keying at every hand-off. Errors compound, hours disappear, and no two parties can confirm they are computing the same NOI from the same inputs.

Brokers

Send a deal any buyer can open on day one, at no cost to them.

Buyers

Ingest the rent roll and assumptions directly. Spend analyst time on judgment, not data entry.

Appraisers

Audit the inputs and the method line by line. The math is open source.

What a .ore file carries

ModuleHolds
propertyIdentity, location, type, physicals (SF, unit count, clear height, docks, power)
rentRollLeases with rent steps, escalations, NNN / NN / MG / Gross recoveries, free rent, TI/LC, options; vacant suites
expensesOperating expenses with recoverability and growth
marketAssumptionsMarket rent, growth, downtime, renewal probability, leasing costs
valuationDCF, direct cap, sales comparison, and cost inputs
debtOptional loan terms for levered returns
provenanceWho produced the file, when, and from what sources

ORE is for every commercial property type. Version 0.1 is deepest on industrial, where the examples started; office, retail and multifamily files are accepted, and the engine says what it has not modeled yet. Every example deal has locked expected outputs, so any implementation of the engine can prove it computes the same answers.

Help build it

ORE is early and open. Two kinds of help matter most right now:

Real estate people

Bring the lease structures, expense arrangements, and underwriting conventions the format can't express yet. Edge cases harden the spec.

Developers

The engine is TypeScript with a golden-file test suite. Pick up a scoped issue, or start the Python port.
