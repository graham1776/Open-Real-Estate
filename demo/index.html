ORE Viewer

Open Real Estate format — see the deal in 30 seconds. Runs entirely in your browser; nothing is uploaded.
Drop .ore files here or click to choose — one file shows the deal, several show the portfolio.
A .ore file is standard JSON — property, rent roll, expenses, assumptions, and valuation in one self-contained file.
ORE (Open Real Estate) — open format, open math. Outputs computed by the ORE reference engine; any simplification applied to a file is named in its Warnings tab.
